## Story
**Como** founder da Oraclum
**Eu quero** conectar minha conta do Instagram a um App da Meta com as permissões certas
**Para que** o motor de publicação (IG-02) tenha como falar com a API sem precisar de mim toda vez.

## Contexto

A Instagram Graph API tem 2 caminhos de autenticação hoje:

| Caminho | Exige Página do Facebook vinculada? | Permissões |
|---|---|---|
| **Instagram Login** (mais novo) | Não | `instagram_business_basic` + `instagram_business_content_publish` |
| **Facebook Login** (tradicional) | Sim | `instagram_basic` + `instagram_content_publish` + `pages_read_engagement` |

Não sei qual desses caminhos a conta @oraclum já suporta sem ver o painel — isso faz parte do que esta story precisa descobrir na prática, não assumir. Se a conta já é Business/Creator e o caminho Instagram Login estiver disponível, é a rota mais simples (menos telas, sem depender de uma Página do Facebook). Se não, cai no caminho tradicional via Facebook Login.

## Passo a passo (founder executa, Claude documenta e confere o resultado)

1. **Confirmar que @oraclum é conta Profissional (Business ou Creator)** — Configurações → Conta → é obrigatório pra API de publicação; conta pessoal não funciona.
2. **Criar o App na Meta** em `developers.facebook.com/apps` → tipo "Business" → adicionar o produto "Instagram" (ou "Instagram Graph API", dependendo do que o painel oferecer no momento).
3. **Tentar o caminho Instagram Login primeiro** (mais simples): conectar a conta @oraclum direto no App, sem precisar de Página do Facebook. Se o painel não oferecer essa opção pra essa conta, seguir pro caminho tradicional.
4. **Caminho tradicional (fallback):** garantir que @oraclum está vinculada a uma Página do Facebook (Configurações do Instagram → conta vinculada); conectar essa Página ao App.
5. **Gerar o token de acesso.** Preferir token de **System User** via Business Manager (não expira, mais estável) sobre token de usuário de longa duração (~60 dias, precisa renovação manual). Se só o de usuário estiver disponível nesse momento, documentar a data de expiração pra IG-04 não quebrar sem aviso.
6. **Adicionar o token e o Instagram Business Account ID ao `.env`** (nunca commitados): `IG_ACCESS_TOKEN`, `IG_BUSINESS_ACCOUNT_ID`.
7. **Validar com uma chamada simples e read-only**, sem publicar nada: `GET /{IG_BUSINESS_ACCOUNT_ID}?fields=username,media_count` — confirma token + ID certos antes de qualquer coisa que escreva.

## Critérios de Aceite

- [x] Documentado no Dev Record desta story: qual caminho foi usado, tipo de token gerado, e o que se sabe (e não se sabe) sobre expiração.
- [x] `GET /{IG_BUSINESS_ACCOUNT_ID}/content_publishing_limit` funciona (`quota_usage: 0`) — confirma que a permissão de publicação está de fato concedida, não só leitura básica.

### O que foi descoberto na execução (não estava previsto de antemão)

- **Caminho usado: Instagram Login puro, confirmado.** O founder criou o App (tipo Business), foi direto pro fluxo Instagram — nenhuma Página do Facebook foi conectada, e não foi preciso.
- **Dois hosts de API diferentes, e eles NÃO são intercambiáveis:**
  - Token `IGAA...` (gerado no App Dashboard) → funciona **só** em `graph.instagram.com`. Testado contra `graph.facebook.com` → erro `"Cannot parse access token"`.
  - Token `EAA...` (gerado no Gerenciador de Negócios, System User) → é do ecossistema `graph.facebook.com`, mas **não alcança a conta @oraclumtech** hoje (`/me/accounts` vazio, `GET /{IG_ID}` com esse token → "Object with ID does not exist... missing permissions"). A conta nunca foi conectada como ativo do Business Manager — só foi conectada via Instagram Login direto no App. Guardado no `.env` como `IG_ACCESS_TOKEN`; o token permanente **não foi usado** (documentado aqui pra não se perder, caso IG-04 precise de um caminho sem expiração no futuro — aí sim vale conectar a conta como ativo do Business Manager).
  - Consequência prática pro IG-02: todo código deste épico fala com `graph.instagram.com`, usando o `user_id` (não o `id` alternativo) devolvido por `/me` como `IG_BUSINESS_ACCOUNT_ID`.
- **Expiração do `IG_ACCESS_TOKEN` NÃO confirmada.** Tentei duas rotas pra verificar/estender programaticamente: `grant_type=ig_exchange_token` (erro "session key invalid" — sugere que esse token já não é do tipo elegível pra troca, possivelmente já emitido de longa duração pelo próprio dashboard) e `debug_token` via app token (erro "Cannot get application info" — esse App não tem o produto Facebook Login habilitado, então esse endpoint clássico não se aplica aqui). **Não inventei uma duração** — o founder deve conferir na tela onde gerou o token (App Dashboard → gerador de token) se ela mostrou uma validade explícita, e isso deve entrar no Change Log antes de IG-04 ser liberada pra produção.
- Ambas as chamadas de aceite rodaram com sucesso lendo do `.env` de verdade (não só valores soltos em teste manual).
- **Confirmado com o founder:** conta é @oraclumtech mesmo (correta); App **não publicado/Live** — e está certo assim, não é pendência. Pra conta própria em modo Desenvolvimento (Admin/Tester do App), a API já funciona sem App Review — validado na prática pelo `content_publishing_limit` ter respondido com permissão real.
- **2ª tentativa do token permanente, após o founder atribuir a conta como ativo do System User:** retestei — mesmo erro (`Object with ID does not exist... missing permissions`). Causa confirmada: o token precisava ser **gerado de novo** depois da atribuição (o que existia até então foi emitido antes).
- **3ª tentativa (token gerado de novo após a atribuição):** ✅ funciona. `GET /{IG_ID}?fields=username,media_count` via `graph.facebook.com` devolveu `username: oraclumtech, media_count: 1` (batendo com o post real da IG-02). `debug_token` confirma: `type: SYSTEM_USER`, `expires_at: 0`, `data_access_expires_at: 0`, `is_valid: true` — **não expira**. Resolve de vez a pendência de expiração deste documento. Guardado em `.env` como `IG_ACCESS_TOKEN_SYSTEM_USER` — ainda **não** trocado como padrão (host diferente: `graph.facebook.com` vs `graph.instagram.com` do token ativo); reservado pra IG-04, onde não-expirar é o que importa.
