## 📌 BEM-VINDO AO MBA META PERFORMANCE ENGINEERING

O **MBA Meta Performance Engineering** é a formação de referência absoluta no mercado latino-americano para profissionais de tráfego, growth, engenharia de dados e marketing science. 

Este programa foi desenhado para superar definitivamente a gestão tática baseada em "hacks de gerenciador", transformando você em um **Engenheiro de Performance**: um profissional capaz de operar na interseção entre o algoritmo de entrega da Meta, engenharia de dados (CAPI/APIs), estatística aplicada, inteligência criativa e decisões estratégicas de negócios.

## 📐 FILOSOFIA DO MÉTODO: O CICLO CIENTÍFICO DO GESTOR

Todas as lições, exercícios e projetos desta apostila seguem rigorosamente o **Ciclo Científico do Gestor**:

```
[OBSERVAÇÃO] ➔ [PERGUNTA] ➔ [HIPÓTESE] ➔ [MÉTRICA] ➔ [EXPERIMENTO] 
       ▲                                                    │
       └───── [DECISÃO (Scale/Hold/Kill)] ◄─── [EVIDÊNCIA] ◄┘
```

### Três Regras Invioláveis do Programa:
1. **Não confundir correlação com causalidade:** Um CPA baixo coincidente com a troca de um anúncio não prova que o anúncio foi a causa. Entender a causa exige métodos de incrementabilidade e grupos de controle.
2. **Não confundir resultado com explicação:** Olhar o Ads Manager não é entender o leilão. Entender exige dominar a fórmula do Valor Total ($V$), a pontuação de qualidade e as taxas de ação estimadas (EAR).
3. **Não automatizar o que você não sabe executar manualmente:** Agentes de IA e automações só devem ser aplicados sobre processos cujo diagnóstico e lógica determinística foram completamente masterizados.

## 🛠️ O PROJETO PRÁTICO: CONSTRUÇÃO DO META OS

Ao longo da leitura e estudo dos 16 módulos, você construirá o **Meta Performance OS** (Sistema Operacional de Performance Meta Ads), uma arquitetura modular em Python e SQL para automação, análise estatística e supervisão agêntica:

```
/meta-os
├── /collector      # Scripts de extração síncrona e assíncrona (Marketing API)
├── /analytics      # Algoritmos de anomalias, séries temporais e atribuição
├── /creative       # Taxonomia automática e detecção de fadiga criativa
├── /automation     # Motor de regras determinísticas e alertas via Slack/Telegram
├── /agents         # Agentes de IA (Analyst, Auditor, Scientist, Operator)
└── /skills         # Skills customizadas para MCP e Claude Code
```

1. **Estude com o ambiente aberto:** Mantenha o Gerenciador de Anúncios, o Meta for Developers (Graph API Explorer) e seu ambiente Python (VS Code / Claude Code) ativos.

3. **Valide a teoria na prática:** Compare os conceitos expostos (como janelas de atribuição, EMQ e curvas de saturação) com a realidade das suas contas de anúncio.
