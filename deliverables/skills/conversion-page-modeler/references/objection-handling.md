# Mapeamento de objeções

Toda página de alta conversão é, no fundo, uma sequência de objeções neutralizadas
na ordem certa. Na Etapa 3, extraia as objeções REAIS do público do usuário e
ligue cada uma a uma seção.

## As 5 objeções universais (e onde tratá-las)
| Objeção | Tradução do lead | Onde neutralizar |
|---------|------------------|------------------|
| **"Não funciona / é hype"** | "Será que entrega mesmo?" | Mecanismo + prova profunda |
| **"Não funciona PARA MIM"** | "Meu caso é diferente." | Depoimentos de perfis variados · FAQ |
| **"Não tenho tempo/skill"** | "É complicado demais." | Seção "como funciona" (3 passos) · bônus |
| **"Não confio / é arriscado"** | "E se eu me arrepender?" | Garantia / risco reverso |
| **"Está caro"** | "Vale o preço?" | Oferta empilhada + ancoragem + custo de não agir |

## Como extrair as objeções do público do usuário
Pergunte / infira:
- O que faz o lead hesitar 1 segundo antes de comprar?
- Que tentativas anteriores frustraram esse público?
- Qual crença errada precisa ser quebrada para ele dizer sim?

## Regra de ouro
A objeção é tratada **antes** de pedir a ação correspondente. Preço só depois do
valor e da prova. Cada FAQ responde a uma objeção real — nunca uma pergunta de fachada.
