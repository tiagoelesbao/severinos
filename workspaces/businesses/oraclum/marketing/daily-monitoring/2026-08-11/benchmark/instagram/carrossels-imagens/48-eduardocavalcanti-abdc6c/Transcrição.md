# Transcrição Estruturada (Carrossel) — O Claude Code agora pode controlar o seu iPhone.

**Plataforma:** ig-carousel  ·  **Slides:** 8

## 📝 Caption / Descrição original

O Claude Code agora pode controlar o seu iPhone.

Não porque a Apple abriu o sistema.

Ele usa o Espelhamento do iPhone como olhos e mãos: captura a tela, lê o texto e envia toque, digitação e swipe pelo Mac.

No vídeo oficial, o agente abre o Waymo, encontra uma corrida de US$ 41,40 e para antes de contratar.

A tela virou caminho. O gasto continua com o humano.

O projeto bateu 1.423 estrelas em 3 dias e 11 horas.

Eu instalei no Mac. O comando oficial quebrou. Corrigi a dependência, rodei o diagnóstico e confirmei a parte que vídeo viral costuma esconder: para funcionar, o terminal precisa de Acessibilidade e Gravação de Tela.

É acesso pesado.

A tese não é “Claude entrou no iPhone”.

É outra:

Quando não existe API, o agente começa a operar a interface como gente.

API quando existe.
Tela quando precisa.
Humano antes do risco.

A IA ganhou alcance.
A responsabilidade continua sendo nossa.

Quer testar no seu Mac? Comenta IPHONE que eu te mando o projeto no direct.

Demonstração e projeto: @shawn_pana · phone-harness.

PRA CIMA. 🦞
