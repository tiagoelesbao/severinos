# Outreach Readiness Checklist

**Objetivo:** Validar que tudo está pronto antes de abordar creators qualificadas.

---

## Pré-requisitos
- [ ] ICP-C do cliente validado (icp-readiness-checklist)
- [ ] Creators qualificadas com Score > 7
- [ ] Scripts de outreach gerados e personalizados
- [ ] Link de tracking (UTM/Cupom) preparado
- [ ] PDF de Gamificação / Jornada Viral atualizado
- [ ] WhatsApp do hunter configurado e ativo

## Scripts Prontos
- [ ] DM personalizada gerada (com referência a post específico)
- [ ] Variação selecionada (Ganho / Social Proof / Escassez)
- [ ] WhatsApp pitch preparado
- [ ] Follow-up D+1 preparado
- [ ] Follow-up D+3 preparado
- [ ] Follow-up D+7 preparado

## CRM
- [ ] Creator registrada no ClickUp (List Prospecção)
- [ ] Status: "qualified" no pipeline
- [ ] Dados completos (handle, score, nicho, fonte)

---

**Gate:** Todos os itens ✅ = Pode iniciar abordagem.
