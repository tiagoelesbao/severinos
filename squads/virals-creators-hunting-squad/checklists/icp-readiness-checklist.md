# ICP-C Readiness Checklist

**Objetivo:** Validar que o ICP-C está completo antes de iniciar o pipeline de hunting.

---

## Dados da Marca
- [ ] Nome da marca preenchido
- [ ] Segmento/nicho definido
- [ ] Produto principal identificado
- [ ] Público-alvo da marca descrito

## Perfil da Creator (ICP-C)
- [ ] Demographics definidos (gênero, idade, localização)
- [ ] Nicho principal e sub-nichos definidos
- [ ] Plataforma principal selecionada (TikTok/IG/ambos)
- [ ] Tipo de conteúdo esperado (UGC, review, tutorial)
- [ ] Requisito de rosto/corpo definido
- [ ] Tom de voz descrito

## Métricas Mínimas
- [ ] Range de followers definido (min/max)
- [ ] Engagement rate mínimo definido
- [ ] Frequência mínima de posts definida

## Referências
- [ ] Pelo menos 3 hashtags de referência listadas
- [ ] Pelo menos 2 creators de referência listadas
- [ ] Red flags identificadas

## Termos da Parceria
- [ ] Modelo de contrato definido (Starter/Growth/Premium)
- [ ] Faixa de compensação definida (fixo + comissão)
- [ ] Entregáveis mensais definidos
- [ ] Exclusividade definida (sim/não)

---

**Gate:** Todos os itens acima devem estar ✅ para prosseguir para Fase 1.
**Se incompleto:** Retornar ao cliente para preenchimento.
