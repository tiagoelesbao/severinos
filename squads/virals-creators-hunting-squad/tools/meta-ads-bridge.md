# Tool: Meta Ads Library Bridge

**Type:** Playwright Scraper
**Script:** `scripts/meta-adslibrary-monitor.js`
**Agents:** @hunter-scout (Mae)
**Status:** v1 (Playwright scraping) — API decision pending

## Description

Monitora Meta Ads Library para identificar marcas rodando ads UGC e creators associados. Dados são públicos (transparência do Meta).

## Usage

```bash
node scripts/meta-adslibrary-monitor.js --keyword "suplemento" --country BR
node scripts/meta-adslibrary-monitor.js --advertiser "Brand Name"
```
