# Task: Performance Tracking

**ID:** VH-TASK-403
**Phase:** 4 — Gerenciamento
**Agent:** @hunter-manager (Jason)
**Execution Type:** Agent
**Status:** template

---

## Objetivo

Rastrear performance mensal de creators ativas e atualizar CRM.

## Input

- Creators ativas no CRM Hunter
- Dados de entregáveis e resultados

## Output

- Performance Score atualizado por creator
- Alertas para creators underperforming

## Action Items

1. Para cada creator ativa:
   a. Verificar entregáveis do mês (quantidade de vídeos/posts)
   b. Verificar métricas de performance (views, engagement, conversão)
   c. Calcular Performance Score mensal
   d. Comparar com meta de entregáveis
2. Identificar underperformers (< 70% da meta)
3. Identificar top performers (> 120% da meta)
4. Atualizar Performance Score no ClickUp CRM Hunter
5. Gerar alertas para L10

## Acceptance Criteria

- [ ] Performance Score atualizado para todas as creators
- [ ] Underperformers identificados
- [ ] Top performers identificados
- [ ] CRM atualizado
