Runbook dos canais

Como gerar o conteúdo de cada canal sem uma LLM executando nada — comando a comando, na ordem, com o que conferir entre um passo e outro.

Tudo aqui foi executado e medido. Não há comando inventado: onde um número aparece, ele saiu de uma medição.

00 · Pré-requisitos

Antes de começar

Três coisas precisam estar de pé. Quando uma falta, o passo que depende dela falha com mensagem confusa em vez de dizer o que está faltando.

O quêComo ligarComo saber que subiu
ComfyUI
narração e geração de imagem		 ComfyUI_windows_portable\run_nvidia_gpu.bat abre 127.0.0.1:8188
Chave do Pexels
acervo de vídeo		 variável PEXELS_API_KEY echo %PEXELS_API_KEY% responde
ffmpeg
todo o vídeo		 no PATH ffmpeg -version responde

Todo comando roda a partir da raiz do repositório e sempre com -X utf8 — sem isso, qualquer acento na saída derruba o script no Windows.

Nunca rode dois em paralelo

Os scripts de vídeo usam as oito threads da CPU e gravam temporários com nome previsível. Dois processos ao mesmo tempo não terminam mais rápido, e já aconteceu de um ler os quadros do outro e concluir "nenhuma faixa de texto encontrada" — sem erro nenhum.

02 · Bora de Bola

Episódio longo

Nove etapas. O runbook completo, com as decisões de formato, está em apps/canal-futebol/ESTEIRA.md — o que segue é a sequência executável. Todos os comandos rodam de dentro de apps/canal-futebol.

Pauta — o que aconteceu hoje

python -X utf8 ../pauta-futebol/pauta.py       # RSS: mercado, bastidor, polêmica
python -X utf8 ../pauta-futebol/fonte_api.py  # ESPN: o que o jogo gerou

Saem pautas ranqueadas de 0 a 100 com o motivo de cada uma ter subido. Você escolhe uma e preenche o fato.json — ação, alvo e consequência. Deixar campo vazio é melhor que preencher com adivinhação: o título só pode prometer o que a fonte sustenta.

Embalagem — título e thumb, antes do roteiro

python -X utf8 ../regra-de-3/gerador.py --nicho futebol --fato 00-pauta/fato.json
python -X utf8 thumb/gera_thumb.py {slug}

Por que antes

70 a 75% da primeira avaliação do algoritmo é o clique. Título escrito depois do roteiro descreve; escrito antes, promete. O roteiro passa a receber uma promessa a cumprir, não um resumo.

Roteiro

Escrito à mão em {slug}/01-roteiro/roteiro.md, em blocos ## BLOCO N. Ele existe para cumprir a promessa do título nos primeiros 45 segundos.

Narração

python -X utf8 narra_comfy.py {slug}       # precisa do ComfyUI no ar
python -X utf8 audita_narracao.py {slug}   # transcreve de volta e mede o erro

A auditoria mede fala, não ortografia. Erro alto num bloco quase sempre é nome próprio que o modelo não conhece — corrige-se no dicionário PRONUNCIA do narra_comfy.py, não no roteiro.

B-roll — três camadas, não uma

python -X utf8 broll/acervo.py {slug}         # vídeo genérico (Pexels)
python -X utf8 broll/fotos_do_fato.py {slug}  # as fotos que os portais publicaram
python -X utf8 broll/cartelas.py {slug}       # o texto, em camada transparente

Aqui você olha — o acervo mente

Abra 03-takes/acervo/_CONFERIR.jpg antes de montar. O banco devolve "parecido", não "o que foi pedido", e take errado num vídeo de notícia não é ilustração fraca — é informação errada.

Áudio

python -X utf8 mixa.py {slug}

Montagem

python -X utf8 monta.py {slug} --rascunho   # 480p, para conferir
python -X utf8 monta.py {slug}              # 1080p

Sempre o rascunho primeiro. Ele leva um minuto; o final leva dez. Nunca renderize em 1080 algo que você ainda não viu.

Guarda de imagem

python -X utf8 audita_camadas.py {slug}

Confere na imagem se as cartelas entraram. Tem um limite conhecido: não detecta cartela repetida em intervalos não contíguos — já aprovou uma que aparecia três vezes porque cada intervalo passava sozinho.

Pack de publicação

python -X utf8 pack.py novo {slug} --titulo "..." --estilo E3
python -X utf8 pack.py estado              # o estado de todos os episódios

03 · Bora de Bola

Curtos derivados

O curto herda o acervo do episódio longo. Por isso ele custa minutos, não horas — e por isso o corte é reconhecido como do canal quando aparece no feed.

cd apps/canal-estoico

python -X utf8 narra_comfy.py {slug} --curto --canal-dir ...\canais\bora-de-bola
python -X utf8 fecha_narracao_curto.py {slug} --canal futebol
python -X utf8 monta_curto.py {slug} --canal futebol --rascunho --herda-de {slug-longo}
python -X utf8 monta_curto.py {slug} --canal futebol --herda-de {slug-longo}

O --herda-de aponta para o episódio longo cujo acervo o curto vai usar. Sem ele, o curto cai no banco genérico do canal.

04 · Canal estoico

Curtos

Mesma esteira, trocando o canal. A diferença real é de conteúdo: no estoico o take é atmosfera — mármore, vela, céu. Qualquer um serve, porque o roteiro não nomeia o que está na tela.

cd apps/canal-estoico

python -X utf8 acervo_curto.py {slug} --canal estoico
python -X utf8 fecha_narracao_curto.py {slug} --canal estoico
python -X utf8 monta_curto.py {slug} --canal estoico --rascunho
python -X utf8 monta_curto.py {slug} --canal estoico

Os longos do estoico não passam por aqui — são montados no apps/video-studio, e o caminho está em docs/PIPELINE-LITE.md.

05 · Curiosidades Animais + Placas de Aviso

Os dois canais de TikTok

Estes dois são roteirizados por especificação. Você não escreve YAML: descreve a peça em poucas linhas num arquivo Python e o gerador produz o roteiro, o curto.yaml e o prompt do hook.

5.1 · Descrever a peça

Abra apps/canal-estoico/lote_dark.py. Há dois dicionários: CUR (contagem regressiva) e AVI (placa em seis blocos). Copie uma entrada existente e troque o conteúdo.

"CUR-l10-meu-assunto-40s": {
    "titulo": "Os animais mais X do mundo",
    "hook": "photorealistic ... vertical composition",   # a cena improvável
    "itens": [
        ("Quatro", "o bicho",
         "Primeira frase de explicação. Segunda frase.",
         "english pexels query", ["subject"], None),
        # 4 ou 5 itens, do maior número para o 1
    ],
    "fecho": "Comenta aí ...",
    "fecho_q": ("closing scene query", ["scene"]),
},

A regra do exige — a que mais custou caro

A lista depois da consulta é o que a descrição do Pexels tem de citar. Ela carrega só o sujeito, nunca o cenário.

["shrimp","mantis","reef"] aceitou coral-reef, reef-shark e seahorse-in-reef no bloco do camarão-louva-a-deus. A palavra de cena é a que o banco tem aos milhares — então é ela que passa.

O último campo é um prompt de geração. Preencha quando o banco provavelmente não tem a espécie: cobra-coral não existe no Pexels, e as 42 respostas das duas consultas eram pôr-do-sol, naja, cobra-d'água e salamandra. Com o prompt, o pipeline gera a espécie certa em vez de mostrar outra.

Uma peça de placas

"AVI-l09-minha-placa-40s": {
    "placa": "o que a placa proíbe",
    "pict": "cuidado-bicho",       # nao-alimentar | nao-toque | cuidado-bicho
    "onde": "numa estrada de parque",
    "leitura": "Bro, essa placa mostra ...?",
    "hook": "photorealistic ... uncluttered",   # FUNDO LIMPO no terço superior
    "rima": "bicho que ...",       # o insert tem a MESMA condição do assunto
    "payoff": ["Frase 1.", "Frase 2.", "Frase 3."],
    "consultas": [
        ("english query", "cenario-estrada", 3, ["road"]),
        ("english query", "reativo", 3, ["dog"]),
        ("english query", "fofo", 2, ["puppy"]),
        ("english query", "dependente", 3, ["dog","stray"]),
        ("english query", "payoff", 2, ["scene"]),
    ],
},

A placa tem de ser real e o payoff honesto. O gancho é o estranhamento, não a mentira — nos sete vídeos modelados, o bloco final sempre explica o que a placa de fato é.

5.2 · Gerar o pack

cd apps/canal-estoico
python -X utf8 lote_dark.py --lista       # ver tudo o que está declarado
python -X utf8 lote_dark.py CUR-l10-meu-assunto-40s
python -X utf8 lote_dark.py --todos       # regerar o lote inteiro

Escreve 01-roteiro/roteiro.md, 01-roteiro/hook.txt e curto.yaml, e imprime quantas palavras e quantos segundos de fala a peça terá. Leia o roteiro — é a última chance barata de corrigir texto.

5.3 · Rodar a esteira

python -X utf8 roda_lote.py CUR-l10-meu-assunto-40s --ate acervo

python -X utf8 roda_lote.py CUR-l10-meu-assunto-40s

5.4 · O que o motor imprime, e o que significa

41 de 41 segmentos com take ancorado na fala
hook gerado de 3.0s + 41 segmentos · corte a 1.1s · 0 repeticoes consecutivas
49 legendas em libass · 132 janelas de karaoke · margem 190 px
3 camadas do formato (emoji, botao, placa) ancoradas na fala
LinhaTem de serSe não for
N de N ancoradoos dois números iguais alguma âncora não casou — o motor imprime qual
repetições consecutivassempre 0 algum bloco ficou com um clipe só; aumente o n ou declare imagem
N camadas do formatoigual ao que o YAML declara uma camada não achou a âncora na fala

06 · Entrega

O original sem legenda

Quando a peça é modelada num vídeo de terceiro, entregamos o original limpo ao lado do nosso corte, em 04-final/original-limpo.mp4.

cd apps/video-tools

python -X utf8 limpa_legenda.py "caminho\do\original.mp4"
#   só detecta e imprime as faixas encontradas

python -X utf8 limpa_legenda.py "caminho\do\original.mp4" -o "...\04-final\original-limpo.mp4"

Reconstrói o fundo atrás do texto com LaMa, a 0,30 s por quadro na CPU — cerca de dez minutos num vídeo de 60 s. No fim ele roda o próprio detector na saída e avisa se sobrou texto.

Se o LaMa não estiver instalado:

python -m pip install --no-deps simple-lama-inpainting

O --no-deps é necessário: sem ele o pip tenta compilar uma versão antiga do numpy e falha por não achar compilador.

07 · Aprovação

O que olhar antes de aprovar

Cinco conferências. As três primeiras o motor entrega de graça; as duas últimas exigem olho.

#O quêOnde
1repetições consecutivas = 0o motor imprime
2todas as âncoras casaramo motor imprime
3número de camadas bate com o YAMLo motor imprime
4o take mostra o que a locução nomeia 10 quadros espalhados pelo vídeo
5o CTA não cobre a legenda um quadro no segundo do CTA

Para tirar um quadro:

ffmpeg -ss 12.5 -i curto.mp4 -frames:v 1 quadro.png

Um número que vale medir nos canais de TikTok

A voz do vídeo final tem de ficar perto de 128 Hz, que é a da referência. Medir no curto.mp4, não no vo.mp3 — já aconteceu de o clone sair certo em 127,7 Hz e a montagem derrubar para 108,6.

08 · Repertório

Armadilhas já pagas

Passo que diz "pronto" sem ter feito o trabalho

Aconteceu três vezes em dois dias, em lugares diferentes. O cache de narração dizia (mantido) devolvendo a voz antiga; a transcrição valia por existir e alinhava a legenda a um áudio que não estava mais lá; e um filtro do ffmpeg era recusado em silêncio, devolvendo o quadro cru.

A defesa: quando o resultado parecer bom demais ou idêntico ao anterior, apague o artefato e refaça. Todos os scripts refazem o que não existe.

Número herdado de outra calibração

Cinco vezes o mesmo erro: um número medido num contexto foi copiado para outro e quebrou em silêncio.

NúmeroVeio deQuebrou porque
margem 120 pxsquad de farming linha centrada chega a x=960; a coluna de botões começa em 900
fator 0,728fonte Montserrata Impact mede 0,8168
guarda luma ≤ 110canal estoicoacervo de bicho é claro
pitch 0,88voz da casao clone já chega em 127,7 Hz
239 wpmoutro vídeo do benchmarka referência fala a 128

Guarda que olha um item por vez não vê padrão

O audita_camadas.py aprovou uma cartela que aparecia três vezes porque cada intervalo passava sozinho. O filtro de acervo aprovou uma modelo de estúdio com uma píton no pescoço como cobra-coral porque duração, orientação e tom estavam certos — ninguém olhava o assunto.

Sempre rascunho antes do final

O rascunho sai em 540×960 e leva um a dois minutos. O final leva de cinco a dez. Todo defeito que já apareceu era visível no rascunho.

09 · Expansão

Abrir um canal novo

Um canal é uma entrada no dicionário CANAIS do apps/canal-estoico/monta_curto.py mais uma pasta em disco. Vinte linhas, não um arquivo novo — é o que faz as correções chegarem em todos os canais de uma vez.

1 · A entrada no motor

"meu-canal": {
    "curtos": os.path.join(_CANAIS, "pasta-do-canal", "curtos"),
    "trilha": os.path.join(_TRILHAS, "02-leitos", "...", "leito.wav"),
    "realce": "0x22DD22",          # cor da palavra em destaque
    "realce_ass": "&H0022DD22",    # a MESMA cor, em AABBGGRR
    "rotulo": "Nome do Canal",
    "cta": "Segue para mais",
    "grade": "eq=saturation=1.06:contrast=1.08",
    "pingpong": False,             # True só quando o take é atmosfera
    "corte": 1.1,                  # segundos por segmento
    "voz": 1.0,
    "pitch": 1.0,
},

Os dois campos que erram calados

realce_ass é a mesma cor em AABBGGRR, não em RRGGBB — invertida. Cor errada aqui não dá erro: sai outra cor na legenda.

pingpong só pode ser True quando o take é atmosfera. Bicho, jogada e carro têm direção; rodar de trás para frente perde o sentido e o espectador percebe.

2 · A pasta

canais/pasta-do-canal/
├── channel-brief.yaml     avatar, tabus, duração-alvo
├── thumb-system.yaml      grade, tipografia, cor, regra de rosto
├── title-patterns.md      o que já foi usado — não repetir
└── curtos/                um diretório por peça

Sem channel-brief.yaml o canal ainda não existe como canal: o primeiro trabalho é de fundação, e nenhum episódio abre antes.

3 · Se o canal usar voz clonada

ffmpeg -i referencia.mp4 -vn -ac 1 -ar 24000 ^
  -af "atrim=18.2:30.4,asetpts=PTS-STARTPTS,highpass=f=70,afftdn=nr=10:nf=-28,loudnorm=I=-18:TP=-2:LRA=9" ^
  "...\ComfyUI\input\ref-nome.wav"

Vinte a trinta segundos de fala contínua bastam. Depois passe --voz-ref ref-nome.wav na narração — e deixe voz e pitch em 1.0, porque o clone já entrega o timbre e o ritmo da referência.
